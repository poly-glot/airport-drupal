Meridian Airport is a fictional airport created for this demonstration website. Nothing on this site describes a real place or service.

## Using this website

We want as many people as possible to be able to use this website. You should be able to:

- zoom in up to 400% without text spilling off the screen or content being lost
- use the whole site with a keyboard only, with a visible focus outline on every link, button and form field
- navigate with a screen reader, using headings, landmarks and a skip link to the main content
- use the site with JavaScript turned off, including the flight board and travel notices
- turn off animation, using your device's reduced motion setting

For help at the airport itself, see Special assistance.

Link: Special assistance -> /help/special-assistance.html

## Conformance status

This website is designed to conform fully to the Web Content Accessibility Guidelines (WCAG) version 2.2 at level AA. Where we know of a limitation, we list it below.

## What we have done

- Every page has one main heading, headings in order, and landmarks for the header, navigation, main content and footer.
- Text and interactive elements meet the AA colour contrast ratios. We calculated every colour pair rather than judging by eye.
- Flight statuses use a word as well as a coloured dot, so nothing relies on colour alone.
- Every form field has a visible label, and optional fields are marked in words.
- Main buttons and links are at least 44 by 44 pixels, and every other control is at least 24 by 24 pixels.
- Maps and illustrations that carry information have a text description. Decorative images are hidden from screen readers.
- Photographs have alternative text that describes what they show.
- Tables have header cells, so screen readers announce the column for each value.
- Links make sense on their own. Where the visible text is short, such as "Read more", hidden text adds the context.

## How we tested

We tested this website on 3 October 2026. Every page was:

- checked with an automated HTML validator
- checked with an automated accessibility tool against WCAG 2.2 level AA
- checked by hand with a keyboard only, at desktop and mobile widths, in an up-to-date desktop browser

Automated tools cannot find every problem, so we also reviewed headings, link text, focus order and form errors by hand.

## Known limitations

- **Live information.** The flight board plays a short, scripted set of gate and status changes when the page opens, then stops. Screen readers announce each change. Security wait times and travel notices are a fixed example and do not update.
- **Schematic maps.** The airport and terminal maps are simplified drawings. The same information is given in the text next to each map.
- **Demonstration forms.** Forms on this site do not send what you type anywhere. Required fields are checked by your browser, so the wording of those messages depends on the browser you use.
- **Links to other sites.** Some links, such as airline booking and social media links, go nowhere in this demonstration. They are marked as not available.
